# Webspark Test Project

Single-page layout with responsive gallery, rows/tiles view switch, and adaptive UI for desktop, tablet, and mobile.

## Features
- Two gallery views: rows and tiles
- Responsive layout for header and gallery
- Adaptive decorative background images
- Load more button(is inactive)
- Pure HTML, SCSS, and TypeScript
- Built with Vite

## Tech Stack
- HTML5
- SCSS
- TypeScript
- Vite

## Run Project
1. Install dependencies:
   npm install
2. Start dev server:
   npm run dev
3. Open in browser:
   http://localhost:5173

## Project Structure
- `/src` – main TypeScript logic
- `/styles` – SCSS styles
- `/public/images` – images and icons

## Notes
- Rows mode shows all posts
- Tiles mode shows only first 8 posts
- Gallery layout changes via CSS classes
